# rinogelardi.com

Static site served by GitHub Pages on the apex domain `rinogelardi.com`.
Currently a temporary "work in progress" landing page; the full bilingual site is planned for 2027.

- `index.html`: the page (no external requests, no build step).
- `favicon.svg`: the RG monogram.
- `CNAME`: the custom domain GitHub Pages serves. Do not delete it: removing it unlinks the domain.
- `.nojekyll`: tells Pages to serve the files as they are, without Jekyll processing.

Publish: commit and push to `main`; Pages redeploys in about a minute.
Brand rules and decisions: `BRAND_Immagine_Coordinata.md`; DNS: `INFRA_Presenza_Professionale.md`
(both in the "Libera Professione Claude" folder).
